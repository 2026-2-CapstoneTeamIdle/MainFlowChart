# 체력 및 피해 | Feature Validation Checklist

Feature 10 · 총 20개 검증 항목

대상 모듈: HealthDamageSystemModule, HealthComponent

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 피해 처리

- [ ] 01. 적 공격이 플레이어에게 명중하면 체력이 감소한다.
- [ ] 02. 명중하지 않은 공격은 체력을 감소시키지 않는다.
- [ ] 03. 설정된 피해량만큼 정확히 체력이 감소한다.
- [ ] 04. 0 이하의 피해량은 무시된다.
- [ ] 05. 체력은 0 미만으로 내려가지 않는다.
- [ ] 06. 이미 사망한 대상에 사망 처리가 중복 발생하지 않는다.

## 체력 상태

- [ ] 07. 게임 시작 시 현재 체력이 최대 체력으로 설정된다.
- [ ] 08. 최대 체력 변경 시 현재 체력이 유효 범위로 보정된다.
- [ ] 09. 회복 시 최대 체력을 초과하지 않는다.
- [ ] 10. 사망 상태에서 일반 회복이 적용되지 않는다.
- [ ] 11. 체력 변경 이벤트가 현재값과 최대값을 제공한다.
- [ ] 12. HUD가 있다면 체력 변경이 표시에 반영된다.

## 게임 오버

- [ ] 13. 플레이어 체력이 0이 되면 게임 오버 상태가 된다.
- [ ] 14. 게임 오버 이벤트는 한 번만 발생한다.
- [ ] 15. 적의 체력 0은 플레이어 게임 오버를 발생시키지 않는다.
- [ ] 16. 게임 오버 후 플레이어 입력이 제한된다.
- [ ] 17. 결과 화면 또는 재시작 흐름으로 전환할 수 있다.
- [ ] 18. 재시작 시 체력과 게임 오버 상태가 초기화된다.
- [ ] 19. 여러 피해 원인이 동시에 발생해도 체력 결과가 결정적이다.
- [ ] 20. 피해와 게임 오버 처리 중 예외 로그가 발생하지 않는다.

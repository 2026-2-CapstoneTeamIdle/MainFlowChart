적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 기본 점프

- [ ] 01. 지면에서 점프 입력 시 점프가 실행된다.

- [ ] 02. 점프하면 Rigidbody2D의 Y 방향 속도가 양수가 된다.

- [ ] 03. 점프 후 플레이어의 Y 좌표가 증가한다.

- [ ] 04. 점프 후 중력에 의해 상승 속도가 감소한다.

- [ ] 05. 최고점에 도달한 뒤 플레이어가 하강한다.

- [ ] 06. 바닥에 도착하면 정상적으로 착지한다.

- [ ] 07. 착지 후 Y 방향 속도가 안정된다.

## 점프 조건

- [ ] 08. 공중에서 점프 입력을 해도 허용되지 않은 추가 점프가 발생하지 않는다.

- [ ] 09. 착지 후 새로운 점프 입력으로 다시 점프할 수 있다.

- [ ] 10. 점프 입력이 없으면 지면에서 자동으로 점프하지 않는다.

- [ ] 11. 공중에서 점프 입력을 계속 유지해도 의도하지 않은 연속 점프가 발생하지 않는다.

- [ ] 12. 착지 직전에 입력한 점프가 설정된 점프 버퍼 시간 내에서 실행된다.

- [ ] 13. 점프 버퍼 시간이 만료되면 과거 입력으로 점프하지 않는다.

## 물리 및 이동

- [ ] 14. 점프 중 오른쪽 이동 입력으로 X 좌표를 증가시킬 수 있다.

- [ ] 15. 점프 중 왼쪽 이동 입력으로 X 좌표를 감소시킬 수 있다.

- [ ] 16. 점프 속도를 변경하면 실제 최대 점프 높이가 달라진다.

- [ ] 17. 공중에서 발판에 충돌하면 물리 엔진이 정상적으로 충돌을 처리한다.

- [ ] 18. 벽이나 천장에 충돌해도 플레이어가 Collider를 관통하지 않는다.

## 예외 및 연동

- [ ] 19. 착지 판정에서 플레이어 자신의 Collider를 지면으로 잘못 인식하지 않는다.

- [ ] 20. 게임 재시작 후 점프 버퍼와 지면 판정이 정상적으로 초기화된다.

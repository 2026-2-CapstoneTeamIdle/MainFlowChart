# 게임 타이머 | Feature Validation Checklist

Feature 16 · 총 30개 검증 항목

대상 모듈: GameTimerModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 시간 측정

- [ ] 01. 타이머를 시작하면 경과 시간이 증가한다.
- [ ] 02. 양수 델타 시간만큼 경과 시간이 증가한다.
- [ ] 03. 0 또는 음수 델타 시간은 무시된다.
- [ ] 04. 기간이 설정된 타이머는 남은 시간을 계산한다.
- [ ] 05. 남은 시간은 0 미만으로 내려가지 않는다.
- [ ] 06. 기간이 없는 타이머를 누적 타이머로 사용할 수 있다.

## 제어

- [ ] 07. 타이머를 일시정지할 수 있다.
- [ ] 08. 일시정지 중에는 경과 시간이 변하지 않는다.
- [ ] 09. 일시정지된 타이머를 다시 시작할 수 있다.
- [ ] 10. 재설정 시 경과 시간이 0으로 초기화된다.
- [ ] 11. 자동 시작 설정이 초기화 시 반영된다.
- [ ] 12. 옵션 메뉴로 게임이 멈추면 타이머도 멈춘다.

## 완료와 표시

- [ ] 13. 경과 시간이 설정 기간에 도달하면 완료 상태가 된다.
- [ ] 14. 완료 이벤트는 한 번만 발생한다.
- [ ] 15. 완료 후 타이머가 추가로 진행하지 않는다.
- [ ] 16. 완료 이벤트를 승리·패배 조건에 연결할 수 있다.
- [ ] 17. HUD가 있다면 경과 또는 남은 시간을 표시한다.
- [ ] 18. 초 단위 표시가 음수 또는 NaN으로 나오지 않는다.
- [ ] 19. 시간 변경 이벤트가 경과와 남은 시간을 제공한다.
- [ ] 20. 장시간 타이머 실행 중 예외 로그가 발생하지 않는다.

## 완성도 및 회귀 검증

- [ ] 21. 게임 타이머 기능의 입력 또는 트리거가 한 번 발생할 때 핵심 동작도 한 번만 실행된다.

- [ ] 22. 게임 타이머 기능의 초기 상태가 씬 시작 시 명세된 기본값과 일치한다.

- [ ] 23. 게임 타이머 기능의 경계값과 최대·최소 상태에서 값이 허용 범위를 벗어나지 않는다.

- [ ] 24. 게임 타이머 기능 실행 중 일시정지와 재개 후 상태와 입력 처리가 일관되게 복원된다.

- [ ] 25. 게임 타이머 기능이 여러 대상에 동시에 적용되어도 대상별 상태가 서로 섞이지 않는다.

- [ ] 26. 게임 타이머 기능의 성공과 실패 결과가 UI 또는 런타임 상태로 즉시 확인된다.

- [ ] 27. 게임 타이머 기능과 승리·패배 조건이 동시에 발생해도 최종 게임 상태가 하나로 확정된다.

- [ ] 28. 게임 타이머 기능을 연속 반복해도 중복 이벤트, 유실, 메모리 누적이 발생하지 않는다.

- [ ] 29. 게임 타이머 기능 관련 오브젝트가 비활성화되거나 제거될 때 구독과 임시 상태가 정리된다.

- [ ] 30. 게임 타이머 기능을 포함한 전체 플레이 흐름을 재시작해도 동일한 입력으로 동일한 결과를 재현한다.

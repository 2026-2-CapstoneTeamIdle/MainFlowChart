# 저장 및 불러오기 | Feature Validation Checklist

Feature 17 · 총 20개 검증 항목

대상 모듈: SaveSystemModule, GameStateStoreModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 저장

- [ ] 01. 현재 GameStateStore 스냅샷을 저장할 수 있다.
- [ ] 02. 문자열, 정수, 실수 상태값을 저장할 수 있다.
- [ ] 03. 저장 시 기존 저장 슬롯을 일관되게 갱신한다.
- [ ] 04. 저장 완료 후 저장 존재 여부가 참이 된다.
- [ ] 05. 저장 성공 이벤트가 발생한다.
- [ ] 06. 빈 상태저장소도 예외 없이 저장할 수 있다.

## 불러오기

- [ ] 07. 저장 데이터가 있으면 불러오기가 성공한다.
- [ ] 08. 저장 데이터가 없으면 불러오기가 거짓을 반환한다.
- [ ] 09. 불러오기 성공 시 문자열 값이 복원된다.
- [ ] 10. 불러오기 성공 시 정수 값이 복원된다.
- [ ] 11. 불러오기 성공 시 실수 값이 복원된다.
- [ ] 12. 불러오기 성공 이벤트가 발생한다.
- [ ] 13. 저장 시점 이후에 변경된 임시 상태가 저장값으로 덮어써진다.

## 삭제와 연동

- [ ] 14. 저장 데이터를 삭제할 수 있다.
- [ ] 15. 삭제 후 저장 존재 여부가 거짓이 된다.
- [ ] 16. 삭제 후 불러오기가 안전하게 실패한다.
- [ ] 17. 아이템 수집량을 저장 상태에 포함할 수 있다.
- [ ] 18. 점수를 저장 상태에 포함할 수 있다.
- [ ] 19. 잘못된 저장 데이터가 게임 실행 파일을 변경하지 않는다.
- [ ] 20. 저장·불러오기·삭제 반복 중 예외 로그가 발생하지 않는다.

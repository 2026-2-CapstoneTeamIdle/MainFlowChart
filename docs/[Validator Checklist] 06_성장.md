# 성장 | Feature Validation Checklist

Feature 06 · 총 30개 검증 항목

대상 모듈: ExperienceSystemModule (뱀서류) / StatSystemModule (그 외 장르)

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 경험치 및 레벨 성장

- [ ] 01. 경험치 획득 시 현재 경험치가 증가한다.

- [ ] 02. 음수 또는 0의 경험치 입력이 의도하지 않은 레벨 상승을 발생시키지 않는다.

- [ ] 03. 누적 경험치가 레벨업 기준 미만이면 레벨이 유지된다.

- [ ] 04. 누적 경험치가 레벨업 기준에 도달하면 레벨이 증가한다.

- [ ] 05. 레벨업 후 남은 경험치가 올바르게 유지된다.

- [ ] 06. 충분한 경험치를 한 번에 획득하면 여러 레벨 상승이 처리된다.

- [ ] 07. 레벨업 후 다음 레벨의 필요 경험치가 설정된 규칙에 따라 갱신된다.

- [ ] 08. 레벨업 시 LevelGained 이벤트가 발생한다.

- [ ] 09. 레벨업 시 강화 선택 기능이 있는 게임에서는 선택지가 표시된다.

- [ ] 10. 강화 선택 후 지정된 능력치가 실제로 변경된다.

## 능력치 성장

- [ ] 11. 성장 행동을 수행하면 대상 능력치가 변경된다.

- [ ] 12. 능력치 증가량이 설정된 수치와 일치한다.

- [ ] 13. 능력치 감소 행동을 수행하면 지정된 수치만큼 감소한다.

- [ ] 14. 능력치가 설정된 최댓값을 초과하지 않는다.

- [ ] 15. 능력치가 설정된 최솟값 아래로 내려가지 않는다.

- [ ] 16. 서로 다른 능력치가 독립적으로 관리된다.

- [ ] 17. 능력치 변경 시 Changed 이벤트가 발생한다.

## 시스템 연동

- [ ] 18. 성장한 능력치가 공격력·이동 속도 등 연결된 게임 기능에 실제 반영된다.

- [ ] 19. 성장 결과가 HUD나 상태 화면에 정상적으로 반영된다.

- [ ] 20. 저장·불러오기가 제공되는 경우 성장 상태가 정상적으로 복원된다.

## 완성도 및 회귀 검증

- [ ] 21. 성장 기능의 입력 또는 트리거가 한 번 발생할 때 핵심 동작도 한 번만 실행된다.

- [ ] 22. 성장 기능의 초기 상태가 씬 시작 시 명세된 기본값과 일치한다.

- [ ] 23. 성장 기능의 경계값과 최대·최소 상태에서 값이 허용 범위를 벗어나지 않는다.

- [ ] 24. 성장 기능 실행 중 일시정지와 재개 후 상태와 입력 처리가 일관되게 복원된다.

- [ ] 25. 성장 기능이 여러 대상에 동시에 적용되어도 대상별 상태가 서로 섞이지 않는다.

- [ ] 26. 성장 기능의 성공과 실패 결과가 UI 또는 런타임 상태로 즉시 확인된다.

- [ ] 27. 성장 기능과 승리·패배 조건이 동시에 발생해도 최종 게임 상태가 하나로 확정된다.

- [ ] 28. 성장 기능을 연속 반복해도 중복 이벤트, 유실, 메모리 누적이 발생하지 않는다.

- [ ] 29. 성장 기능 관련 오브젝트가 비활성화되거나 제거될 때 구독과 임시 상태가 정리된다.

- [ ] 30. 성장 기능을 포함한 전체 플레이 흐름을 재시작해도 동일한 입력으로 동일한 결과를 재현한다.

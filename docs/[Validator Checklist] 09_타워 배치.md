# 타워 배치 | Feature Validation Checklist

Feature 09 · 총 21개 검증 항목

대상 모듈: PrototypeTowerBuildController, PrototypeTowerWeapon

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 배치 입력

- [ ] 01. 배치 메뉴에서 타워를 선택할 수 있다.

- [ ] 02. 타워 선택 시 선택한 타워 종류가 정상적으로 기록된다.

- [ ] 03. 타워 배치 입력 시 지정된 위치에 타워가 생성된다.

- [ ] 04. 생성된 타워의 종류가 선택한 타워와 일치한다.

- [ ] 05. 서로 다른 전투 수치를 가진 타워를 최소 2종 이상 선택해 배치할 수 있다.

- [ ] 06. 배치된 타워의 좌표가 선택한 배치 위치와 일치한다.

- [ ] 07. 배치 모드를 취소하면 타워가 생성되지 않는다.

## 배치 조건

- [ ] 08. 배치가 허용된 영역에서는 정상적으로 타워를 배치할 수 있다.

- [ ] 09. 배치가 금지된 영역에서는 타워를 생성할 수 없다.

- [ ] 10. 이미 타워가 존재하는 배치 슬롯에 중복 배치할 수 없다.

- [ ] 11. 배치에 필요한 재화가 충분할 때 배치가 성공한다.

- [ ] 12. 재화가 부족할 때 타워 배치가 실패한다.

- [ ] 13. 배치 성공 시 설정된 타워 가격만큼 재화가 감소한다.

- [ ] 14. 배치 실패 시 재화가 감소하지 않는다.

- [ ] 15. 배치 실패 시 타워 오브젝트가 남지 않는다.

## 전투 시스템 연동

- [ ] 16. 배치된 타워에 공격 모듈이 정상적으로 연결된다.

- [ ] 17. 적이 공격 범위에 진입하면 배치한 타워가 공격을 시작한다.

- [ ] 18. 타워가 발사한 투사체가 적에게 피해를 준다.

- [ ] 19. 공격 범위 밖의 적은 타워 공격 대상으로 선택되지 않는다.

- [ ] 20. 여러 타워를 배치하면 각각 독립적으로 공격한다.

- [ ] 21. 타워를 배치한 후에도 웨이브 생성과 적 이동이 정상적으로 진행된다.

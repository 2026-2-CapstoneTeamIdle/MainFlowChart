# 자동 공격 | Feature Validation Checklist

Feature 03 · 총 20개 검증 항목

대상 모듈: AutoTargetSystemModule, ProjectileSystemModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 타겟 탐색

- [ ] 01. 공격 범위 안에 적이 있으면 자동으로 공격을 시작한다.

- [ ] 02. 공격 범위 안에 적이 없으면 투사체를 발사하지 않는다.

- [ ] 03. 설정된 공격 범위 밖의 적을 공격하지 않는다.

- [ ] 04. 공격 범위 경계에 있는 적이 정의된 범위 판정에 따라 처리된다.

- [ ] 05. 여러 적이 있으면 가장 가까운 적을 선택한다.

- [ ] 06. 적이 이동하면 변경된 위치를 기준으로 공격 방향을 계산한다.

- [ ] 07. 적이 공격 범위를 벗어나면 해당 적을 계속 공격 대상으로 선택하지 않는다.

- [ ] 08. 적이 아닌 오브젝트는 공격 대상으로 선택하지 않는다.

## 공격 처리

- [ ] 09. 플레이어의 직접적인 공격 입력 없이 투사체가 발사된다.

- [ ] 10. 투사체가 선택된 목표 방향으로 발사된다.

- [ ] 11. 투사체 충돌 시 대상 체력이 감소한다.

- [ ] 12. 설정된 Damage 값에 따라 피해량이 적용된다.

- [ ] 13. 설정된 AttacksPerSecond에 따라 공격 주기가 유지된다.

- [ ] 14. 설정된 ProjectileCount만큼 투사체가 생성된다.

## 예외 및 연동

- [ ] 15. 공격 대상이 사망하면 유효한 다른 대상을 탐색한다.

- [ ] 16. 타겟 오브젝트가 제거되어도 NullReferenceException이 발생하지 않는다.

- [ ] 17. 적이 대량으로 등장해도 공격 주기와 투사체 생성 수가 유지된다.

- [ ] 18. 플레이어 이동 중에도 자동 공격이 실행된다.

- [ ] 19. 강화 기능으로 공격력이 변경되면 실제 피해량도 변경된다.

- [ ] 20. 게임 재시작 후 공격 주기와 대상 탐색이 정상적으로 초기화된다.

# 대화 선택 | Feature Validation Checklist

Feature 08 · 총 20개 검증 항목

대상 모듈: DialogueRunnerModule, ChoiceBranchSystemModule, FlagSystemModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 대화 진행

- [ ] 01. 대화 시작 시 첫 번째 대사가 표시된다.

- [ ] 02. 다음 대사 입력을 하면 다음 대사로 이동한다.

- [ ] 03. 대사 순서가 설계된 시나리오와 일치한다.

- [ ] 04. 대화에 해당하는 화자 정보가 정상적으로 표시된다.

- [ ] 05. 마지막 대사 이후 대화 완료 이벤트가 발생한다.

## 선택지 처리

- [ ] 06. 선택지가 필요한 지점에서 선택지가 표시된다.

- [ ] 07. 선택지의 텍스트와 ID가 정상적으로 연결된다.

- [ ] 08. 선택지 A를 선택하면 A에 지정된 결과가 적용된다.

- [ ] 09. 선택지 B를 선택하면 B에 지정된 결과가 적용된다.

- [ ] 10. 선택하지 않은 선택지의 효과는 실행되지 않는다.

- [ ] 11. 선택지 선택 시 ChoiceSelected 이벤트가 발생한다.

- [ ] 12. 선택지 선택 결과에 따라 지정된 플래그가 갱신된다.

## 조건 및 분기

- [ ] 13. 특정 플래그가 필요한 선택지는 조건 충족 시 선택할 수 있다.

- [ ] 14. 조건을 충족하지 못한 선택지는 선택할 수 없다.

- [ ] 15. 조건을 충족하지 않은 선택을 시도해도 게임 상태가 변경되지 않는다.

- [ ] 16. 선택 후 해당 플래그에 연결된 시나리오 분기가 실행된다.

- [ ] 17. 서로 다른 선택 결과에 따라 서로 다른 대화가 진행된다.

- [ ] 18. 선택 결과에 따른 엔딩 조건이 올바르게 반영된다.

## 예외 및 연동

- [ ] 19. 선택지를 빠르게 여러 번 입력해도 동일한 선택이 중복 처리되지 않는다.

- [ ] 20. 저장·불러오기를 제공하는 경우 선택 결과와 진행 위치가 정상적으로 복원된다.

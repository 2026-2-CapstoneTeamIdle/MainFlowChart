# 8방향 이동 | Feature Validation Checklist

Feature 02 · 총 20개 검증 항목

대상 모듈: TopDownMovementModule (top_down_movement)

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 방향별 이동

- [ ] 01. 오른쪽 입력 시 X 좌표가 증가한다.

- [ ] 02. 왼쪽 입력 시 X 좌표가 감소한다.

- [ ] 03. 위쪽 입력 시 Y 좌표가 증가한다.

- [ ] 04. 아래쪽 입력 시 Y 좌표가 감소한다.

- [ ] 05. 오른쪽 위 입력 시 X, Y 좌표가 모두 증가한다.

- [ ] 06. 오른쪽 아래 입력 시 X는 증가하고 Y는 감소한다.

- [ ] 07. 왼쪽 위 입력 시 X는 감소하고 Y는 증가한다.

- [ ] 08. 왼쪽 아래 입력 시 X, Y 좌표가 모두 감소한다.

## 이동 처리

- [ ] 09. 입력이 없으면 플레이어의 이동 속도가 0이 된다.

- [ ] 10. 수평 이동 속력이 설정한 MoveSpeed와 일치한다.

- [ ] 11. 대각선 이동 속력이 수평 이동 속력보다 커지지 않는다.

- [ ] 12. 이동 방향을 반대로 전환하면 속도 방향이 정상적으로 변경된다.

- [ ] 13. 이동 중 입력을 해제하면 설정된 방식대로 정지한다.

- [ ] 14. MoveSpeed를 변경하면 실제 이동 속도도 변경된다.

## 예외 및 연동

- [ ] 15. 이동 중 벽에 충돌하면 벽을 관통하지 않는다.

- [ ] 16. 이동 중 다른 Collider와 충돌해도 물리 처리가 정상적으로 작동한다.

- [ ] 17. 이동 입력을 빠르게 변경해도 비정상적인 위치 이동이 발생하지 않는다.

- [ ] 18. 게임 재시작 후에도 이동 기능이 정상적으로 초기화된다.

- [ ] 19. 플레이어가 사망 상태라면 게임 규칙에 따라 이동이 제한된다.

- [ ] 20. 이동하면서 공격해도 이동과 공격 시스템이 정상적으로 실행된다.

# 점수 기록 | Feature Validation Checklist

Feature 15 · 총 20개 검증 항목

대상 모듈: ScoreSystemModule, GameStateStoreModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 점수 누적

- [ ] 01. 양수 점수를 현재 점수에 더할 수 있다.
- [ ] 02. 점수를 여러 번 추가하면 결과가 누적된다.
- [ ] 03. 0 점 추가는 점수를 변경하지 않는다.
- [ ] 04. 음수 점수 추가는 무시된다.
- [ ] 05. 점수 변경 이벤트가 최종 점수를 제공한다.
- [ ] 06. 리셋 시 점수가 0이 된다.

## 게임 연동

- [ ] 07. 적 처치 시 설정된 점수가 지급된다.
- [ ] 08. 아이템 수집 시 설정된 점수가 지급된다.
- [ ] 09. 목표 달성 시 보너스 점수를 지급할 수 있다.
- [ ] 10. 한 번의 이벤트가 점수를 중복 지급하지 않는다.
- [ ] 11. 게임 오버 후 추가 점수 획득을 제한할 수 있다.
- [ ] 12. HUD가 있다면 현재 점수가 즉시 표시된다.
- [ ] 13. 플레이어 스탯 화면에 현재 점수가 표시된다.

## 저장과 결과

- [ ] 14. 점수 변경이 GameStateStore에 반영된다.
- [ ] 15. 저장 시 현재 점수가 포함된다.
- [ ] 16. 불러오기 후 저장된 점수를 복원할 수 있다.
- [ ] 17. 결과 화면에 최종 점수가 표시된다.
- [ ] 18. 재시작 정책에 따라 점수를 초기화할 수 있다.
- [ ] 19. 매우 큰 점수를 누적해도 표시가 깨지지 않는다.
- [ ] 20. 점수 누적·리셋 중 예외 로그가 발생하지 않는다.

# 옵션 | Feature Validation Checklist

Feature 11 · 총 20개 검증 항목

대상 모듈: OptionsMenuModule, AudioManagerModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 메뉴 입력

- [ ] 01. 기본 ESC 키로 옵션 메뉴를 열 수 있다.
- [ ] 02. 옵션이 열린 상태에서 ESC 키로 닫을 수 있다.
- [ ] 03. 메뉴의 계속 버튼으로 게임으로 복귀한다.
- [ ] 04. 옵션 메뉴는 다른 HUD 위에 표시된다.
- [ ] 05. 메뉴 열기가 중복 패널을 생성하지 않는다.

## 일시정지와 종료

- [ ] 06. 옵션이 열리면 게임 시간이 멈춘다.
- [ ] 07. 옵션을 닫으면 이전 시간 배율이 복원된다.
- [ ] 08. 옵션 상태에서도 UI 버튼을 조작할 수 있다.
- [ ] 09. 종료 버튼이 종료 요청 이벤트를 발생시킨다.
- [ ] 10. 에디터 테스트에서 종료 요청이 에디터를 강제 종료하지 않는다.

## 소리 조정

- [ ] 11. 마스터 볼륨을 0~100% 범위에서 조정할 수 있다.
- [ ] 12. 0 미만 볼륨 입력은 0으로 보정된다.
- [ ] 13. 100% 초과 볼륨 입력은 100%로 보정된다.
- [ ] 14. 볼륨 변경이 실제 AudioListener에 반영된다.
- [ ] 15. 음악 볼륨을 별도로 조정할 수 있다.
- [ ] 16. 효과음 볼륨을 별도로 조정할 수 있다.
- [ ] 17. 현재 마스터 볼륨이 메뉴에 표시된다.
- [ ] 18. 옵션을 닫은 후에도 변경한 볼륨이 유지된다.
- [ ] 19. 장면에 오디오 모듈이 없어도 마스터 볼륨 조정이 실패하지 않는다.
- [ ] 20. 메뉴 반복 열기·닫기 중 예외 로그가 발생하지 않는다.

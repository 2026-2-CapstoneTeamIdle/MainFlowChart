# 플레이어 스탯 | Feature Validation Checklist

Feature 14 · 총 20개 검증 항목

대상 모듈: PlayerStatDisplayModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 표시 입력

- [ ] 01. 기본 E키로 플레이어 스탯 화면을 열 수 있다.
- [ ] 02. 스탯 화면이 열린 상태에서 E키로 닫을 수 있다.
- [ ] 03. 화면 열기·닫기 API를 직접 호출할 수 있다.
- [ ] 04. 스탯 패널이 HUD 위에 읽을 수 있게 표시된다.
- [ ] 05. 화면을 닫으면 스탯 패널이 입력을 가로채지 않는다.

## 표시 정보

- [ ] 06. 플레이어 현재 체력과 최대 체력을 표시한다.
- [ ] 07. 레벨 시스템이 있으면 현재 레벨을 표시한다.
- [ ] 08. 경험치 시스템이 있으면 현재값과 필요값을 표시한다.
- [ ] 09. 재화 시스템이 있으면 현재 재화를 표시한다.
- [ ] 10. 아이템 시스템이 있으면 전체 수집량을 표시한다.
- [ ] 11. 점수 시스템이 있으면 현재 점수를 표시한다.
- [ ] 12. 선택 장르에 없는 스탯은 오류 대신 생략된다.

## 갱신과 안정성

- [ ] 13. 체력 변경 후 스탯 표시가 갱신된다.
- [ ] 14. 경험치·레벨 변경 후 스탯 표시가 갱신된다.
- [ ] 15. 재화·아이템·점수 변경 후 표시가 갱신된다.
- [ ] 16. 플레이어 오브젝트가 나중에 생성되어도 체력을 찾아 표시한다.
- [ ] 17. 일부 선택 모듈이 없어도 화면을 열 수 있다.
- [ ] 18. 반복 갱신이 스탯 값을 변경하지 않는다.
- [ ] 19. 스탯 화면이 옵션 화면과 서로 독립적으로 작동한다.
- [ ] 20. 반복 열기·닫기 중 예외 로그가 발생하지 않는다.

# 8방향 공격 | Feature Validation Checklist

Feature 01 · 총 20개 검증 항목

대상 모듈: 전용 기존 모듈 없음 (AI 신규 생성 대상)

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 방향별 공격

- [ ] 01. 오른쪽 공격 입력 시 투사체가 오른쪽으로 발사된다.

- [ ] 02. 왼쪽 공격 입력 시 투사체가 왼쪽으로 발사된다.

- [ ] 03. 위쪽 공격 입력 시 투사체가 위로 발사된다.

- [ ] 04. 아래쪽 공격 입력 시 투사체가 아래로 발사된다.

- [ ] 05. 오른쪽 위 공격이 정확한 대각선 방향으로 발사된다.

- [ ] 06. 오른쪽 아래 공격이 정확한 대각선 방향으로 발사된다.

- [ ] 07. 왼쪽 위 공격이 정확한 대각선 방향으로 발사된다.

- [ ] 08. 왼쪽 아래 공격이 정확한 대각선 방향으로 발사된다.

## 공격 처리

- [ ] 09. 공격 입력 후 지정된 시간 안에 투사체가 생성된다.

- [ ] 10. 투사체가 설정된 발사 위치에서 생성된다.

- [ ] 11. 대각선 공격의 투사체 속력이 수평 공격과 일치한다.

- [ ] 12. 투사체가 설정된 방향으로 지속적으로 이동한다.

- [ ] 13. 투사체가 적과 충돌하면 적의 체력이 감소한다.

- [ ] 14. 공격하지 않았을 때 의도하지 않은 투사체가 생성되지 않는다.

## 예외 및 연동

- [ ] 15. 공격 쿨타임 중 추가 공격이 제한된다.

- [ ] 16. 공격 방향을 변경하면 다음 공격부터 변경된 방향이 적용된다.

- [ ] 17. 플레이어가 이동하면서 공격해도 발사 방향이 유지된다.

- [ ] 18. 투사체가 설정된 수명 이후 제거된다.

- [ ] 19. 플레이어 사망 시 공격이 중지된다.

- [ ] 20. 공격으로 적을 처치하면 해당 적의 사망 처리가 실행된다.

# 아이템 수집 | Feature Validation Checklist

Feature 12 · 총 20개 검증 항목

대상 모듈: ItemCollectionSystemModule, GameStateStoreModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 수집

- [ ] 01. 유효한 아이템 ID와 수량을 수집할 수 있다.
- [ ] 02. 수집한 수량이 해당 아이템의 보유량에 누적된다.
- [ ] 03. 서로 다른 아이템이 종류별로 분리되어 저장된다.
- [ ] 04. 전체 수집 수량이 종류별 수량의 합계와 일치한다.
- [ ] 05. 빈 아이템 ID는 수집되지 않는다.
- [ ] 06. 0 이하 수량은 수집되지 않는다.
- [ ] 07. 수집 성공 이벤트가 ID, 획득량, 누적량을 제공한다.

## 사용과 저장

- [ ] 08. 보유량 이하의 아이템을 사용할 수 있다.
- [ ] 09. 아이템 사용 시 보유량과 전체 수량이 함께 감소한다.
- [ ] 10. 보유량을 초과한 사용 요청은 실패한다.
- [ ] 11. 사용 실패 시 아이템 수량이 변하지 않는다.
- [ ] 12. 수량 변경이 GameStateStore에 즉시 반영된다.
- [ ] 13. 아이템 상태가 저장 데이터에 포함될 수 있다.
- [ ] 14. 불러오기 후 아이템 보유량을 복원할 수 있다.

## 연동

- [ ] 15. 필드 수집물과 충돌하면 수집 API가 호출된다.
- [ ] 16. 이미 수집된 필드 오브젝트가 중복 지급하지 않는다.
- [ ] 17. HUD가 있다면 수집 수량이 표시에 반영된다.
- [ ] 18. 플레이어 스탯 화면에 전체 아이템 수량을 표시할 수 있다.
- [ ] 19. 타워 배치·업그레이드 등 다른 시스템이 자원을 안전하게 사용할 수 있다.
- [ ] 20. 연속 수집과 사용 중 예외 로그가 발생하지 않는다.

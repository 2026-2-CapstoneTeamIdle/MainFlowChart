# 공격 | Feature Validation Checklist

Feature 04 · 총 20개 검증 항목

대상 모듈: ProjectileSystemModule (일반 공격 입력 및 연계 로직 별도 확인)

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 공격 입력

- [ ] 01. 공격 입력 시 공격 동작이 시작된다.

- [ ] 02. 공격 입력이 없으면 의도하지 않은 공격이 발생하지 않는다.

- [ ] 03. 공격 입력 시 설정된 공격 오브젝트가 생성된다.

- [ ] 04. 공격 오브젝트가 지정된 위치에서 생성된다.

- [ ] 05. 공격 방향이 플레이어의 조준 또는 바라보는 방향과 일치한다.

## 피해 판정

- [ ] 06. 공격이 적에게 명중하면 체력이 감소한다.

- [ ] 07. 공격이 빗나가면 적의 체력이 감소하지 않는다.

- [ ] 08. 공격 범위 밖의 적에게 피해가 적용되지 않는다.

- [ ] 09. 공격력이 10이라면 방어력 등 보정이 없을 때 체력이 10 감소한다.

- [ ] 10. 적 체력이 0에 도달하면 사망 상태가 된다.

- [ ] 11. 사망한 적에게 추가 공격을 해도 사망 처리가 중복 발생하지 않는다.

- [ ] 12. 하나의 공격이 같은 적에게 중복 피해를 주지 않는다. 단, 다단 히트 공격은 별도 규칙을 따른다.

## 공격 제한

- [ ] 13. 공격 쿨타임 중에는 추가 공격이 제한된다.

- [ ] 14. 쿨타임이 종료되면 다시 공격할 수 있다.

- [ ] 15. 설정된 공격 속도를 변경하면 실제 공격 주기가 달라진다.

- [ ] 16. 플레이어가 사망하면 공격이 불가능하다.

- [ ] 17. 공격 오브젝트의 수명이 끝나면 정상적으로 제거된다.

## 시스템 연동

- [ ] 18. 적 처치 시 설정된 보상 또는 경험치가 지급된다.

- [ ] 19. 공격 효과가 발생할 때 설정된 공격 이벤트가 실행된다.

- [ ] 20. 공격과 이동을 동시에 수행해도 충돌 판정과 피해 처리가 유지된다.

# 타워 업그레이드 | Feature Validation Checklist

Feature 13 · 총 20개 검증 항목

대상 모듈: TowerUpgradeSystemModule, PrototypeTowerWeapon, EconomySystemModule

검증 상태: 전 항목 미실행 · 실제 게임 동작 검증 결과가 아님

판정값: PASS / FAIL / UNVERIFIED / NOT_APPLICABLE

적용 원칙: 사용자 요구사항에 없는 선택 기능은 NOT_APPLICABLE로 처리하고 이유를 기록

## 업그레이드 요청

- [ ] 01. 배치된 타워를 업그레이드 대상으로 선택할 수 있다.
- [ ] 02. 선택한 타워의 현재 레벨을 확인할 수 있다.
- [ ] 03. 현재 레벨에 따라 업그레이드 비용이 계산된다.
- [ ] 04. 유효하지 않은 타워의 비용 조회는 0을 반환한다.
- [ ] 05. 재화가 충분하면 업그레이드가 성공한다.
- [ ] 06. 재화가 부족하면 업그레이드가 실패한다.
- [ ] 07. 실패한 업그레이드는 재화를 차감하지 않는다.

## 수치 변경

- [ ] 08. 성공 시 타워 레벨이 1 증가한다.
- [ ] 09. 성공 시 타워 공격력이 증가한다.
- [ ] 10. 성공 시 타워 공격 속도가 증가한다.
- [ ] 11. 성공 시 타워 사거리가 증가한다.
- [ ] 12. 변경된 수치가 실제 투사체 피해량에 반영된다.
- [ ] 13. 변경된 공격 속도가 실제 발사 주기에 반영된다.
- [ ] 14. 변경된 사거리가 적 탐색 범위에 반영된다.

## 연속 강화와 연동

- [ ] 15. 레벨이 높아질수록 다음 업그레이드 비용이 증가한다.
- [ ] 16. 여러 번 업그레이드해도 수치가 정상적으로 누적된다.
- [ ] 17. 하나의 타워 강화가 다른 타워의 수치를 변경하지 않는다.
- [ ] 18. 서로 다른 타워 종류도 동일한 업그레이드 API를 사용할 수 있다.
- [ ] 19. 업그레이드 성공 이벤트가 변경된 타워를 전달한다.
- [ ] 20. 업그레이드 후 전투가 계속 진행되고 예외 로그가 발생하지 않는다.
